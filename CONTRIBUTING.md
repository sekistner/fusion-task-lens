# Contributing

This is a small advisory prototype. Start with `npm test` and `npm run demo`; no credentials or model calls are required. Describe the user decision your change improves and whether it affects policy, proposed UI, transport or live integration.

Preserve Fusion's native workflow, approval and model-selection authority. Do not add automatic selection as a side effect of observation. Keep recommendation, native resolution and actual session evidence separate. Fixes need a behavioral regression where appropriate; simulated evidence must remain labeled.

Public issues should use synthetic task text and omit secrets, private task content, personal paths, account data and infrastructure details. Do not attach raw provider or runtime logs. The local trial fixture is historical and must not be rewritten to imply newer behavior.

A source change or passing test is not a runtime deployment. Managed installations retain their own packaging and release controls.
